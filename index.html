关于张万江（Edgar）：屏幕背后的工程师

我的开发者之路

我是 张万江（Edgar），一位专注于交互式 Web 体验的前端开发者。我的工程之路始于对「逻辑与美学如何交织」的好奇。 多年来，我不仅打磨了构建可用网站的能力，更致力于打造能给用户留下深刻印象的产品。 我相信 2026 年及以后的 Web，需要的不仅仅是响应式设计，更需要动效、空间感与交互性。

核心技术栈

  • 基础：JavaScript (ES6+)、TypeScript、HTML5、语义化标记与现代 CSS（SCSS / CSS Modules）。
  • 框架与生态：React.js，以及围绕状态管理、路由与复杂 UI 逻辑的 React 生态。
  • 3D 图形与 WebGL：Three.js 与 React Three Fiber (R3F)，自定义着色器、几何优化与资产管理，在浏览器中稳定保持高帧率。
  • 动效：GSAP（GreenSock）与 Framer Motion，编排基于物理的 UI 动效与滚动联动体验。
  • 后端与云端：Node.js、Express，以及七牛云、腾讯云等国内云服务的集成。

作品画廊：精选项目与案例

在 3D 画廊房间中，你可以漫步浏览我最具代表性的开源与个人项目。

FLOWBOARD · 协作白板

FLOWBOARD 是一个单文件、零依赖、类似 Miro 的实时协作白板，使用原生 JavaScript 与 Canvas 构建。 无需后端即可在浏览器中完成多人实时绘制与脑暴，展示了轻量化实时协作的实现思路。

DEAIFY · 去 AI 味

DEAIFY 是一套面向算法 / 系统类代码的「去 AI 化」工具，帮助把机器生成的代码改写得更具人类工程师的风格与可读性。

打工仁账本 · LEDGER

打工仁账本 是一个单文件、可离线运行的记账工具，并内置「真实时薪」工作台， 帮助打工人直观看到每一笔开销对应多少工作时间。

知识综述 · REVIEWS

知识综述 基于腾讯云知（乐享）的语义检索能力，自动聚合资料并生成结构化的综述报告，适合做调研与知识沉淀。

小说转剧本 · NOVEL>SCRIPT

小说转剧本 是一个 AI 小说转剧本工具（基于七牛云），把叙事文本自动拆解为可分镜的剧本结构。

RECALL · 决策引擎

RECALL 是一个本地优先的决策与经验引擎，帮助你把过往决策与结果沉淀下来，形成可复用的判断依据。
